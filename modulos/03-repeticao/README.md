# 03 - Repetição

Exercícios focados em estruturas de repetição e controle de fluxo.

## Conteúdos

- estrutura `enquanto`
- estrutura `repita`
- estrutura `para`
- contadores e acumuladores
- repetições condicionais
- laços de repetição

## Exercícios

20 exercícios, divididos por estrutura:

- `01-enquanto/` (10)
- `02-repita/` (5)
- `03-para/` (5)

## Objetivo

Desenvolver a lógica de repetição em algoritmos utilizando diferentes estruturas de laço.
