# 04 - Funções

Exercícios sobre modularização de código.

## Conteúdos

- criação de funções
- parâmetros
- retorno de valores
- reutilização de código
- recursão

## Exercícios

15 exercícios, divididos por conceito:

- `01-sem-retorno/` (5)
- `02-com-retorno/` (5)
- `03-recursao/` (5)

## Objetivo

Organizar algoritmos em blocos reutilizáveis.
