# 01 - Básico

Exercícios introdutórios de lógica de programação.

## Conteúdos

- entrada e saída de dados
- `variáveis`
- operadores aritméticos (`+`, `-`, `*`, `/`)
- expressões matemáticas simples

## Exercícios

15 exercícios, sem subpastas.

## Objetivo

Desenvolver a base inicial de lógica de programação.
