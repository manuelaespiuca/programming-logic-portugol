# Módulos de Estudo

Esta pasta reúne os módulos utilizados para acompanhar minha evolução em lógica de programação.

## Ordem de Estudo

- `01-basico/`
- `02-condicionais/`
- `03-repeticao/`
- `04-funcoes/`
- `05-vetores/`
- `06-matrizes/`

Cada módulo possui seu próprio `README.md` com os conteúdos, a organização e o objetivo específico.

Após concluir os módulos, os conceitos são aplicados na pasta [`projetos/`](../projetos), que reúne aplicações mais completas.

## Método

- Resolver os exercícios em sequência.
- Praticar com constância.
- Revisar conteúdos anteriores.
- Evoluir passo a passo.
