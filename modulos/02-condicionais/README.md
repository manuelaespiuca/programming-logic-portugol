# 02 - Condicionais

Exercícios focados em tomada de decisão.

## Conteúdos

- estruturas de decisão (`se`, `senao`)
- operadores relacionais (`>`, `<`, `>=`, `<=`, `=`)
- operadores lógicos (`e`, `ou`, `nao`)
- condições compostas

## Exercícios

20 exercícios, sem subpastas.

## Objetivo

Desenvolver lógica de decisão em algoritmos.
