# 05 - Vetores

Exercícios com estruturas de dados unidimensionais.

## Conteúdos

- leitura e escrita de vetores
- percorrer vetores
- busca de valores
- soma e média
- maior e menor elemento
- manipulação de elementos

## Exercícios

15 exercícios, sem subpastas.

## Objetivo

Trabalhar com armazenamento e manipulação de dados em listas.
