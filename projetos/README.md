# Projetos

Aplicações práticas que combinam os conceitos estudados nos módulos anteriores.

## Conteúdos

- condicionais e menus interativos
- repetição
- funções
- vetores
- matrizes

## Projetos

5 projetos, sem subpastas.

1. **01-calculadora-com-menu** — calculadora com menu de opções (básico + condicionais)
2. **02-jogo-adivinhacao** — jogo com tentativas limitadas até acertar o número (repetição)
3. **03-biblioteca-utilidades** — conjunto de funções úteis: conversor de unidades, cálculo de IMC, entre outras (funções)
4. **04-sistema-cadastro** — cadastro de alunos com listagem e busca por nome (vetores)
5. **05-jogo-da-velha** — jogo completo com verificação de vitória e empate (matrizes)

## Objetivo

Aplicar de forma integrada tudo o que foi praticado nos módulos, em projetos mais próximos de situações reais.
