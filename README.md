# Lógica de Programação em Portugol

Repositório de estudo com exercícios e projetos práticos de lógica de programação, escritos em **Portugol**. Organizado por tópico, com dificuldade progressiva, do básico até projetos que integram tudo.

**Total: 100 itens** (95 exercícios + 5 projetos)

## Estrutura

```
├── modulos/
│ ├── 01-basico/ (15 exercícios)
│ ├── 02-condicionais/ (20 exercícios)
│ ├── 03-repeticao/ (20 exercícios)
│ │ ├── 01-enquanto/ (10)
│ │ ├── 02-repita/ (5)
│ │ └── 03-para/ (5)
│ ├── 04-funcoes/ (15 exercícios)
│ │ ├── 01-sem-retorno/ (5)
│ │ ├── 02-com-retorno/ (5)
│ │ └── 03-recursao/ (5)
│ ├── 05-vetores/ (15 exercícios)
│ └── 06-matrizes/ (10 exercícios)
└── projetos/ (5 projetos)
```

Cada módulo tem seu próprio `README.md` com informações sobre os conteúdos abordados, exercícios e objetivo do módulo. Módulos com estruturas ou conceitos distintos (repetição, funções) são divididos em subpastas, enquanto os demais ficam organizados diretamente por número de exercício.

## Projetos

A pasta `projetos/` funciona como uma revisão cumulativa: cada projeto usa os conceitos dos módulos anteriores, em ordem crescente de complexidade.

1. **calculadora-com-menu** — calculadora com menu de opções (básico + condicionais)
2. **jogo-adivinhacao** — jogo com tentativas limitadas até acertar o número (repetição)
3. **biblioteca-utilidades** — conjunto de funções úteis: conversor de unidades, validador de CPF, entre outras (funções)
4. **sistema-cadastro** — cadastro simples de nomes e notas, com opções de listar e buscar (vetores)
5. **jogo-da-velha** — tabuleiro 3x3 jogável no terminal (matrizes)

## Objetivo

Este repositório reúne meus primeiros estudos de lógica de programação, consolidando a base antes de avançar para linguagens e paradigmas mais complexos.
