# Programming Logic in Portugol

Study repository with exercises and practical projects focused on programming logic, written in **Portugol**. Organized by topic, with progressive difficulty, from basic concepts to projects that integrate everything learned.

**Total: 100 items** (95 exercises + 5 projects)

## Structure

```text
├── modulos/
│   ├── 01-basico/ (15 exercises)
│   ├── 02-condicionais/ (20 exercises)
│   ├── 03-repeticao/ (20 exercises)
│   │   ├── 01-enquanto/ (10)
│   │   ├── 02-repita/ (5)
│   │   └── 03-para/ (5)
│   ├── 04-funcoes/ (15 exercises)
│   │   ├── 01-sem-retorno/ (5)
│   │   ├── 02-com-retorno/ (5)
│   │   └── 03-recursao/ (5)
│   ├── 05-vetores/ (15 exercises)
│   └── 06-matrizes/ (10 exercises)
└── projetos/ (5 projects)
```

Each module has its own `README.md` with a list of exercises and specific instructions. Modules with distinct structures or concepts (such as loops and functions) are divided into subfolders. The others are organized directly by exercise number.

## Projects

The `projetos/` folder serves as cumulative practice: each project uses concepts from the previous modules, with progressively increasing complexity.

1. **calculadora-com-menu** — calculator with an options menu (basics + conditionals)
2. **jogo-adivinhacao** — guessing game with a limited number of attempts (loops)
3. **biblioteca-utilidades** — collection of useful functions, such as a unit converter and CPF validator (functions)
4. **sistema-cadastro** — simple system for registering names and grades, with options to list and search (arrays)
5. **jogo-da-velha** — playable 3x3 tic-tac-toe board in the terminal (matrices)

## Goal

This repository brings together my first studies in programming logic, building a solid foundation before moving on to more complex programming languages and paradigms.
